What's included beyond the original design (layout, colours, fonts and copy are unchanged)
- Opening sequence: the big word reveals, containers drop in back-to-front, then the claw opens the first one.
- Soft ground shadows under every container that fade while the claw lifts one.
- Cursor spotlight that lights up the background grid, plus gentle parallax on the big PORTFOLIO word.
- Content is lowered into each container piece by piece; headline numbers (8.8 CGPA, 96%, 82.6%, Rs 13.25 lakh) count up.
- Cards glow where the cursor is; the email button and nav links have hover/focus polish; nav shows the open section.
- Claw status light: green when idle, amber while moving.
- Keyboard: Esc = home, Left/Right = previous/next container, 1-7 = jump to a container.
- Shareable links: index.html#work, #about, #process, #toolkit, #services, #contact open that container directly.
- SEO and sharing: page description, social-preview tags, favicon and Person structured data.
- Respects "reduce motion" system settings (all animation is switched off, everything still works).
